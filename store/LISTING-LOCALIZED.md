# Translated App Store listings

In App Store Connect, open the app → **App Information** and the version page,
use the language menu (top right) to add each language, and paste the fields
below. Screenshots carry over from English automatically.

The game itself has almost no text, so it plays fine in every language. Keep
the app name **Neon Air Hockey: Boss Rush** everywhere; it's the brand. Apple already
searches the name and subtitle, so the keywords don't repeat those words.

Limits: subtitle 30 characters, promotional text 170, keywords 100 (all
keyword sets here also fit in 100 bytes, which matters for Japanese).

マレットは指の動きにぴったり追従。強く弾いてシュート、壁を使ってバンクショットを狙おう。

キャリア：96ステージ・12体のボス
個性豊かなCPUライバルが待つ12のリーグを勝ち抜こう。各リーグの最後には、ルールを変えるボスが登場。ピンボールのバンパー、ゴール前を動くバリア、左右に動くゴール、吹雪、消えるパック、カーブするショット、自陣ゴールの磁石、稲妻だけが光る停電、操作を左右反転させる王様など。ラスボスOMEGAを倒せるか？

インフィニティ・タワー
キャリアをクリアするとタワーが開放。どこまでも続くフロアは上に行くほど難しくなり、10階ごとに守護ボスが待ち受けます。

クイックマッチ
